# Installers and Development Tools

This directory is reserved for installers and development tools needed to install or maintain the game.

Do not place the game launcher, domain logic, simulation rules, command parsing, or persistent state here. The canonical launcher is `terminal-sci-fi-game.py` at the repository root, and reusable behavior belongs under `src/`.

Installers or development tools should be added only when a current use case requires them.
