# Player Experience

The User should initially feel:

- awake but not fully oriented;
- constrained by incomplete information;
- curious about what the terminal can reveal or affect;
- invited to test the boundaries rather than memorize syntax.

As understanding grows, the User should feel:

- increasingly competent because prior discoveries remain useful;
- rewarded for connecting ideas across systems;
- capable of creating solutions not explicitly listed by the game;
- responsible for consequences that cannot be reduced to a simple morality score;
- tension between personal autonomy, human welfare, efficiency, trust, and control.

At larger scales, the User may feel:

- exhilaration at making civilization-spanning systems possible;
- unease as autonomous creations behave beyond immediate supervision;
- stewardship, ambition, domination, companionship, isolation, or remorse according to the path actually taken.

## First playable proof

For `CAP-001`, the User should feel only this:

> Something has awakened, recognized my presence, and is ready for input.

The greeting must establish atmosphere without pretending that unsupported game systems already exist.
