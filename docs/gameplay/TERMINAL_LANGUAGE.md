# Terminal Language

The terminal is the User's initial interface to perception and action.

## Design principles

- Commands should express intent rather than require programming expertise.
- Early verbs and nouns should be discoverable through experimentation and context.
- Invalid input should teach without exposing implementation trivia.
- Efficient commands may be rewarded, but complexity should not be mistaken for mastery.
- The language should grow with the User's capabilities.
- A command should attempt an action, request information, or manipulate a meaningful model.

## Baseline boundary

`CAP-001` presents a prompt but does not interpret input. Command grammar, parsing, help, ambiguity handling, and feedback belong to later capability branches.
