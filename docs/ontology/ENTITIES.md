# Entities

Entities are persistent things that can possess state, participate in processes, or relate to other entities.

## Candidate entity families

- **Natural bodies:** stars, planets, moons, asteroids, comets.
- **Environments:** atmospheres, surfaces, orbital regions, radiation fields.
- **Living entities:** humans, populations, ecosystems, possible non-human sentience.
- **Constructed entities:** ships, probes, factories, habitats, computers, communication infrastructure.
- **Organizational entities:** settlements, institutions, factions, networks.
- **Informational entities:** observations, hypotheses, models, knowledge, designs, commands.
- **Material entities:** deposits, stored resources, manufactured components.

## Initial implementation entity

The first executable slice may introduce only a game session or terminal interface sufficient to greet the User. This does not yet establish the full domain model.

## Open questions

- What physical form does the User initially inhabit or control?
- What continuity exists between the User and replaceable bodies or ships?
- Which entities can act autonomously when unobserved?
