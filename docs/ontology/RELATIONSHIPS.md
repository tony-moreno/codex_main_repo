# Relationships

Relationships connect entities and may carry state, authority, dependency, trust, ownership, containment, location, or information.

## Candidate relationship types

- contains / is contained by
- orbits / is orbited by
- located at / travels toward
- owns / controls / operates
- depends on / supplies
- observes / is observed by
- communicates with
- trusts / distrusts / resists
- produces / consumes
- knows / hypothesizes / is uncertain about
- designed from / manufactured by
- allied with / opposed to / governed by

Relationship mechanics are not yet defined. Add only those required by active capabilities.
