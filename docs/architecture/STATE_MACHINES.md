# State Machines

State machines will document lifecycle behavior when an entity or process has meaningful states, transitions, guards, and failures.

## Candidate future state machines

- game session lifecycle;
- command lifecycle;
- research lifecycle;
- manufacturing job lifecycle;
- ship or probe operational state;
- communication exchange;
- human trust or resistance escalation.

## Baseline

No state machine is approved yet. The first implementation may expose a minimal application lifecycle, but it should not imply unsupported simulation behavior.
