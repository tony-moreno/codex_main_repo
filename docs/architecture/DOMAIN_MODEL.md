# Domain Model

The domain model will translate validated ontology into software responsibilities without replacing the ontology.

## Known conceptual areas

- world state;
- User knowledge state;
- entities and relationships;
- processes and events;
- capabilities and constraints;
- terminal interaction;
- research and design;
- persistence and replay.

## Current boundary

No mature domain objects are yet justified. `CAP-001` requires only enough application structure to launch, render a greeting, and expose a prompt.

Do not create classes for future star systems, ships, resources, research, or factions until an active use case requires their behavior.
